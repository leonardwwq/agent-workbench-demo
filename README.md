# LABU

个人面试作品，可交互的移动 H5 + PC 服务配置 Mock。所有业务、购买、Token 及客户数据均为模拟。无真实模型、服务端、支付、广告投放或消息触达。

使用说明和历史验收结果见《验收记录.md》。

## 本地运行

Node.js 22+，运行 `npm ci`，然后 `npm run dev`。

- 门店 H5：`http://localhost:5173/#/app`
- PC 配置：`http://localhost:5173/#/admin`
- 检查：`npm test`、`npm run build`
- 浏览器流程：`npx playwright test`（默认使用 macOS Chrome，可用环境变量 `PLAYWRIGHT_CHROME_PATH` 指向独立浏览器可执行文件）。

两个入口需在同一浏览器、同一源打开。IndexedDB 持久化，PC 配置通过本地数据库同步到 H5；不跨设备同步。无登录系统，浏览器本地模拟账号，勿填写真实客户资料。

## 建议演示顺序

1. 使用默认经营演示起点。总控输入“这周想增加到店，先做护理体验活动，再邀约老客”，确认行动。
2. 进入获客引流，填写并生成活动方案，编辑保存、确认采用。
3. 进入客户经营，引用该活动、选择客户分组，生成话术并确认模拟触达，登记模拟到店。
4. 查看总控汇总、工作面板和数据总览。
5. 打开未购买的短视频功能；PC 订阅配置加入“短视频脚本”，H5 即时可用；平台停用该能力后，即使有权益也不可执行。
6. 模拟购买额度包，生成脚本并检查精确余额与流水；刷新验证持久化。
7. 如需展示套餐：在“我的”或 PC 重置到购买演示起点，购买固定套餐，收到 4B 模拟 Token 和功能权益。重置会清除所有本地配置与记录。

默认演示商品：订阅 ¥128/月、3B Token；额度包 ¥28、1B；短视频功能 ¥18；固定套餐 ¥158、首次4B。仅为演示占位，不代表真实模型用量报价。K/M/B 为十进制单位，可查看精确余额；每次生成的消耗为模拟固定数值。

## 配置与执行

六个固定 Agent：总控、招聘、引流、运营、客户经营、短视频。订阅直接包含具体能力，另买功能取并集，平台 / 插件开关优先。任务成功时原子写入结果和扣额，失败、中断不扣；重置会使旧任务失效。生成过程中刷新可重试，活动采用后和邀约触达后内容锁定并保留快照。

PC 可调整能力和插件状态、配置四类商品。插件仅为预置配置，不支持真实插件上传、注册和执行。团队和多门店仅为规划占位。
